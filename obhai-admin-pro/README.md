# OBHAI Bangladesh - Dual Role Passenger, Captain & Company Admin HQ

A complete, high-fidelity Web Application representing **OBHAI** (Rahimafrooz Ride-Sharing Platform) featuring **OBHAI CNG**, **OBHAI Moto**, **OBHAI Prime Car**, **Captain Portal**, and the **Company Admin Control Panel** (with live reactive pricing inputs).

---

## 🌟 Key Features

### 1. 🔐 Dedicated Fullscreen Login Gate
- Select your role upon arrival:
  - 🛺 **OBHAI Passenger (যাত্রী প্যানেল)**: Book digital meter CNGs, bikes, and cars in Dhaka.
  - 👨‍✈️ **OBHAI Captain (চালক / ক্যাপ্টেন)**: Accept ride requests, track earnings (`৳ 2,850.00`), and earn target quest bonuses.
  - 🛡️ **Company Admin HQ (কোম্পানি অ্যাডমিন)**: Real-time pricing inputs, coupon publisher, and dispute resolution.
- Includes **"⚡ 1-Click Quick Demo Login"** buttons.

### 2. 🛺 OBHAI Signature Vehicle Fleet
- **OBHAI CNG**: Green CNG Auto-Rickshaw digital meter calculation.
- **OBHAI Moto**: Fastest motorbike rides in Dhaka traffic.
- **OBHAI Prime AC**: Comfortable AC sedan cars.
- **OBHAI Micro**: 7-seater vehicles for family trips.

### 3. 🎛️ Your Pricing Inputs (Company Control Panel)
*Green-accented control card matching your reference image:*
- Store Discount (%)
- Coupon Code (`OBHAI10` / custom)
- bKash / Nagad Cashback (৳)
- Shipping / Surge Cost (৳)
- Sale Price (৳)
- **"🔄 Apply Changes"**: Instantly recalculates all CNG & car fares on the passenger screen without refreshing!

### 4. 🎧 Passenger Disputes & Refund Resolution
- Passengers can file complaints (e.g., CNG meter disconnection, overcharge).
- Admin can review complaints, enter custom refund amounts (৳), and credit the passenger's Obhai Pay wallet live!

---

## 🚀 How to Run

Open `obhai-admin-pro-standalone.html` directly in any web browser.
