# Uber Pro (React Edition) - 3-in-1 Platform

A modern, production-ready React application for the Uber 3-in-1 ecosystem (Customer Passenger, Driver Partner, and Company Admin HQ).

## 🚀 Quick Start (Development Server)

```bash
# 1. Navigate to the project directory
cd /Users/smnazmus11gmail.com/.gemini/antigravity/scratch/uber-react-pro

# 2. Install dependencies
npm install

# 3. Start the Vite development server
npm run dev
```

## ⚡ Instant Browser Preview (Zero Setup)
Double-click `uber-react-pro-standalone.html` in your browser to launch the complete React app instantly without running any local terminal servers!

## 📦 Features Included
- **Auth Gate**: Role switcher for Passenger, Driver, and Admin with 1-click quick demo buttons.
- **Customer Portal**: Interactive Dhaka Leaflet routing, real-time fare calculation with discounts, Uber Cash wallet top-up, and promo coupon manager.
- **Driver Portal**: Online/Offline toggle, live incoming ride radar queue with accept/decline, earnings dashboard, and quest milestones.
- **Company Admin HQ**: "Your Pricing Inputs" green control panel with live typing auto-sync, promo voucher creator/table, and customer dispute resolution inbox with 1-click refund crediting.
- **Persistence**: Full `localStorage` state synchronization across page refreshes.
